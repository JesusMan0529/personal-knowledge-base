## 3.1 线性表的逻辑结构与基本操作

线性表是具有相同数据类型的 $n(n \geq 0)$ 个数据元素的有限序列，记为 $L = (a_0, a_1, ..., a_{n-1})$。其中：

- $a_0$ 是表头元素 (head)，$a_{n-1}$​ 是表尾元素 (tail)
- 每个元素都有自己的位置
- 除 $a_0$​ 外，每个元素有且仅有一个直接前驱
- 除 $a_{n-1}$​ 外，每个元素有且仅有一个直接后继
- 数据元素之间是一对一的线性关系

```Java
public interface ListADT<E>{
    public void clear();				//清空表
    public void append(E it);			//在表尾添加元素
    public void insert(E it);			//在 curr 插入元素
    public E remove();				//删除 curr 的值并返回该位置的元素
    public void setFirst(); 			//将 curr 设置到表头
    public void next();					//将 curr 后移
    public void prev();					//将 curr 前移
    public int length();  				//获取表实际大小
    public void setPosition(int position);	 	//将 curr 设置为 pos
    public E currValue(); 			//获取 curr 的元素值
    public void setValue(E it);			//设置 curr 的元素值
    public boolean isInList();			//判断 curr 是否在线性表中
    public boolean isEmpty(); 			//判断表是否为空
    public boolean isFull();			//判断表是否已经满了
    public void print(); 				//打印表
}
```

## 3.2 链式存储结构的实现技术 

**结点结构**：每个结点含**数据域**（存储元素）和**指针域**（指向后继结点）。
**单向链表**：结点**仅包含指向后继结点**的指针域，逻辑顺序通过指针关联，内存可分散分配。
**带头结点链表**：增设头结点（不存有效数据），**统一空表与非空表的操作逻辑**，简化边界处理。

```Java
public class Link<E>{

    //getter和setter

		//修改结点的数据

        this.element = element;
    }
		
		//获取下一个结点
    public Link getNext() {
        return next;
    }

		//设置下一个结点
    public void setNext(Link next) {
        this.next = next;
    }
}
```

### 2. 单链表类
```Java
//单链表类
public class LinkedList<E> implements ListADT<E> {
    //带有表头结点header node
    private Link<E> head; //头指针
    private Link<E> tail; //尾指针
    protected Link<E> curr; //指向当前元素前驱结点的指针

    private void setUp() { //初始化
        tail = head = curr = new Link<>(null);
    }

    //构造器
    public LinkedList() {
        setUp();
    }

		//清空链表
    @Override
    public void clear() {  
        head.setNext(null);
        curr = tail = head;
    }
    
    //在链表尾部插入元素
    @Override
    public void append(E it) {
        tail.setNext(new Link(it, null));
        tail = tail.getNext();
    }

		//把新元素插到当前元素的前面
    @Override
    public void insert(E it) {
        if (curr == null) {
            System.out.println("no current element");
            return;
        } else {
            curr.setNext(new Link(it, curr.getNext()));
            //若tail == curr，插入新元素后新元素才是真正的尾结点，需要将尾指针后移
            if (tail == curr) {
                tail = curr.getNext();
            }
        }
    }

		//删除并返回当前位置的元素值
    @Override
    public E remove() {
        if(!isInList()) {
		        return null;
				}else{
						E it = (E) curr.getNext().getElement();
						//若当前元素是尾结点，则要将尾指针前移
						if (tail == curr.getNext()){
								tail = curr;
						} 
						//删除当前元素
						curr.setNext(curr.getNext().getNext());
		        return it;
				}
    }

		//将当前位置移到开头
    @Override
    public void setFirst() {
        curr = head;
    }
    
    //将当前位置往后移
    @Override
    public void next() {
        if (curr != null) curr = curr.getNext();
    }

		//将当前位置向前移
    @Override
    public void prev() {
        if (curr == null || curr == head)) {
            curr = null;
            return;
        }
				//从头结点开始查找 curr 所指结点的前驱结点
        Link<E> temp = head;
        while (temp != null && temp.getNext() != curr) {
            temp = temp.getNext();
        }
        //前驱结点的指针前移，当前元素前移
        curr = temp;
    }
    
    //获取链表的实际大小
    @Override
    public int length() {
        int count = 0;
        for (Link temp = head.getNext(); temp!=null ; temp=temp.getNext()) {
            count++;
        }
        return count;
    }
	
		//将当前位置设置到指定位置
    @Override
    public void setPosition(int position) {
		    //从头结点开始
        curr = head;
        for (int i = 0; (curr != null) && (i < position); i++) {
            curr = curr.getNext();
        }
    }
    
    //获取当前位置的元素值
    @Override
    public E currValue() {
       if(!isInList()) return null;
       return (E) curr.getNext().getElement();
    }

		//设置当前位置的元素值
    @Override
    public void setValue(E it) {
        if (!isInList()) {
            System.out.println("no current element");
            return;
        }
        curr.getNext().setElement(it);
    }

		//判断当前元素是否在链表中
    @Override
    public boolean isInList() {
       return (curr != null) && (curr.getNext()!=null);
    }
    
    //判断链表是否为空
    @Override
    public boolean isEmpty() {
        return head.getNext() == null;
    }

		//判断链表是否已满
    @Override
    public boolean isFull() {
        return false; //链表没有固定容量。每次插入元素时，都会动态创建新结点
    }

		//打印链表
    @Override
    public void print() {
        if (isEmpty()) {
            System.out.println("empty");
        } else {
            System.out.print("(");
            for (setFirst(); isInList(); next()) {
                System.out.print(currValue() + " ");
            }
            System.out.println(")");
        }
    }
}
```

## 3.5 实际应用中不同存储结构的选取判断能力

核心判断逻辑：基于**操作频率、访问方式、内存限制、容量需求**四大核心因素，匹配顺序存储（顺序表）与链式存储（链表）的特性差异，具体选取标准如下：

| 应用场景关键词                               | 推荐存储结构   | 核心原因                                         |
| ------------------------------------- | -------- | -------------------------------------------- |
| 频繁**按索引随机访问**（如查第k个元素、排序后取值）          | 顺序表      | 数组下标支持 $O(1)$ 随机访问，无需遍历，效率远高于链表的 $O(n)$ 遍历访问 |
| 频繁**在中间/头部插入/删除**（如日志实时插入、队列调度）       | 链表（带头节点） | 仅需修改指针域（$O(1)$操作），无需移动大量元素，规避顺序表的$O(n)$移动开销  |
| 内存空间紧凑、**存储密度要求高**（如嵌入式设备、数据量大且无频繁修改） | 顺序表      | 无指针域开销，存储密度$100$%（链表因指针占用额外内存，存储密度<$100$%）   |
| 内存碎片多、**无法分配连续大块空间**（如长期运行的服务）        | 链表       | 结点分散存储，无需连续内存，顺序表需连续数组空间，易因内存碎片分配失败          |
| 容量可预测、**无需频繁扩容**（如固定长度的配置表）           | 顺序表      | 初始化时指定容量，避免**扩容开销**；链表无容量限制，结点创建有额外开销        |
| 频繁尾插/尾删（如栈的基础操作、数据采集缓存）               | 顺序表/链表均可 | 顺序表尾插尾删（不扩容时）$O(1)$，链表尾插（记录尾节点）也$O(1)$，按需选择  |
|                                       |          |                                              |
|                                       |          |                                              |

1. 若需 **“查找+修改“** 高频组合（如学生成绩查询与更新），优先**顺序表**；
2. 若需 **“动态增减+遍历”** 高频组合（如购物车商品添加/删除），优先**链表**；
3. 顺序表需要注意扩容策略，例如每次扩为原容量的 1.5 倍；合理设置初始容量，可以减少频繁扩容造成的性能波动；
4. 链表需注意首尾节点记录（如双向链表、循环链表），优化首尾操作效率。

 >[!tip]
 >**扩容开销**：顺序表空间用满后，为了继续添加元素，需要申请更大的连续内存，并把原来的所有元素复制过去。这个过程会消耗时间和额外内存。

### 1. 顺序栈

```Java
public class AStack<E> implements StackADT<E> {
    //构造顺序栈
    private final int DEFAULT_SIZE = 10;
    private int size; //栈最多能容纳的元素个数
    private int top; //可插入位置的下标（栈中有效元素的数量）
    private E[] listArray; //存储栈中元素的数组

    //初始化
    private void setUp(int size) {
        this.size = size;
        top = 0;
        listArray = (E[]) new Object[size];
    }

    //构造器
    public AStack() {
        setUp(DEFAULT_SIZE);
    }

    public AStack(int size) {
        setUp(size);
    }

		//清空栈中所有元素
    @Override
    public void clear() {
        top = 0;
    }
		
		//压栈
    @Override
    public void push(E it) {
        if (top >= size) {
            System.out.println("stack overflow");
            return;
        }
        listArray[top++] = it;
    }

		//出栈（取出并删除栈顶元素）
    @Override
    public E pop() {
        if (isEmpty()){
		        return null;
        }
        return listArray[--top]; //top-1才是存储最顶元素的位置
    }

		//返回栈顶元素
    @Override
    public E topValue() {
        if (isEmpty()){
		        return null;
        }
        return listArray[top-1];
    }
		
		//判断栈是否空
    @Override
    public boolean isEmpty() {
        return top == 0;
    }
		
		//打印栈中的所有元素（默认自顶向下）
    @Override
    public void print() {
        if (isEmpty()){
            System.out.println("empty");
        }
        for (int i = top - 1; i >= 0; i--){
            System.out.println(listArray[i]);
        }
    }
}
```

### 2. 顺序队列（环形结构）

```Java
public class AQueue<E> implements QueueADT<E> {
    //定义顺序队列
    private static final int DEFAULT_SIZE = 10;
    private int max_size; //定义队列的实际最大容纳量+1（用于区分队空和队满）
    private int size; //队列中实际的元素个数
    private int front; //队首元素的前驱元素下标
    private int rear; //队尾元素下标
    private E[] listArray; //存储队列元素的数组
    
    //初始化
    private void setUp(int size){
        this.max_size = size + 1;
        this.size = 0;
        front = rear = 0;
        listArray = (E[]) new Object[size + 1];
    }

		//构造器
    public AQueue() {
        setUp(DEFAULT_SIZE);
    }
    public AQueue(int size){
        setUp(size);
    }

		//清空队列元素
    @Override
    public void clear() {
        front = rear = 0;
        size = 0;
    }

		//入队
    @Override
    public void enqueue(E it) {
		    //队列已满
        if (isFull()){
            System.out.println("queue is full!");
            return;
        }
        rear = (rear + 1) % max_size;
        listArray[rear] = it;
        this.size++;
    }

		//出队
    @Override
    public E dequeue() {
        if (isEmpty()){
            System.out.println("queue is empty");
            return null;
        }
        //队首元素的前驱元素向后移动一格
        front = (front + 1) % max_size;
        size--;
        return listArray[front]; //已经不属于队列
    }

		//获取队首元素
    @Override
    public E firstValue() {
        if (isEmpty()){
            System.out.println("queue is empty");
            return null;
        }
        return listArray[(front + 1) % max_size];
    }

		//判断队列是否为空
    @Override
    public boolean isEmpty() {
        return front == rear;
    }
    
		//判断队列是否已满
    @Override
    public boolean isFull() {
        return front == (rear + 1) % max_size;
    }

		//打印队列
    @Override
    public void print() {
        if (isEmpty()){
            System.out.println("queue is empty");
            return;
        }
        //从真正的队首位置开始
        int temp = (front + 1) % max_size; 
        while((temp != rear){
            System.out.print(listArray[temp] + " ");
            temp = (temp + 1) % max_size; 
        }
        //打印队尾元素
        System.out.println(listArray[temp]);
    }

		//获取元素数量
    @Override
    public int size() {
        return this.size;
    }
}
```
