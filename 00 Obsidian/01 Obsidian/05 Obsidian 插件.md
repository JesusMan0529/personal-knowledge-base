
插件允许用户根据自己的需求，将 Obsidian 从一个基础的 Markdown 编辑器，**扩展**成一个功能无限的瑞士军刀。

Obsidian 的插件分为两大类：**核心插件**和**社区插件**。

### 核心插件

- **定义：** 这些是 Obsidian 软件自带的、官方维护的功能模块。它们默认安装在每个 Obsidian 实例中，但可以根据需要选择开启或关闭。
- **作用：** 提供软件的基础和重要功能，例如笔记之间的**双向链接**、**关系图谱**、**每日笔记**、**模板**、**标签面板**等。
- **应用举例：**
    - **每日笔记 (Daily Notes)：** 快速创建并跳转到当天的笔记，非常适合做每日记录或任务追踪。
    - **画布 (Canvas)：** 让你在一个无限大的白板上自由布局笔记、图片和网页，进行视觉化的思维组织。
    - **模板 (Templates)：** 允许你定义重复使用的笔记结构（如读书笔记、会议记录），提高效率。

#### Daily Notes：每日笔记

Daily Notes 是日记功能的核心插件，让你每天有一篇固定笔记用于记录、规划或反思。

##### 启用与配置

在设置 → 核心插件中开启「日记」。

| 配置项        | 建议值            | 说明                    |
| ---------- | -------------- | --------------------- |
| 日期格式       | YYYY-MM-DD     | 如 2026-05-21，天然按文件名排序 |
| 新建日记的默认文件夹 | 00-日记          | 与普通笔记分离，方便管理          |
| 模板文件位置     | Templates/日记模板 | 指定每日日记的模板             |

##### 快捷操作

点击左侧边栏的日历图标，Obsidian 会在指定文件夹中自动创建当天的日记文件。

#### Canvas：无限白板

Canvas 是 Obsidian 内置的无限画布工具，用**卡片和连线**来组织思想、规划项目、绘制图表。

##### 创建 Canvas

在文件列表中右键选择「新建白板」。

Canvas 文件以 .canvas 扩展名存储，**本质上是一个 JSON 文件**，可以用文本编辑器查看和编辑。

##### 添加卡片

在 Canvas 中**双击空白处创建卡片**，或拖入以下内容：

- Markdown 笔记文件（自动创建链接卡片）
- 图片（拖入即显示）
- 网页链接（自动创建嵌入卡片）

##### 连线与分组

鼠标悬停在卡片边缘会出现连接点，拖拽到另一张卡片即可创建连线。

连线可以添加文字标签（如「依赖于」「导致」「参考」），并选择颜色和线型。

框选多张卡片后右键选择「创建分组」，可以为它们添加背景色和标题。

##### 适用场景

| 场景       | 用法                              |
| -------- | ------------------------------- |
| 头脑风暴     | 自由创建卡片，用连线表达想法之间的关系             |
| 项目规划     | 任务卡片 + 依赖连线 + 分组表示阶段，直观展示项目全景   |
| ==知识地图== | 将核心概念笔记拖入 Canvas，用连线展示概念之间的引用关系 |
| 写作大纲     | 每张卡片是一个章节要点，拖动排序，连线表示逻辑关系       |

> Canvas 与图谱不同：图谱是 Obsidian 根据你的双链自动生成的，Canvas 是你**主动手工布局**的。前者是发现，后者是规划。

#### Outline：大纲面板

大纲插件在右侧边栏显示当前文档的**标题树**。

##### 核心功能

- 自动解析文档中的 `# ## ###` 标题，生成层级树
- 点击标题可快速跳转到文档对应位置
- 当前正在阅读的标题会高亮显示
- 拖拽标题可以在文档中重新排列章节顺序

大纲面板对于**长文档**的导航尤其有用——当你有一篇 3000 字的学习笔记时，不再需要手动滚动寻找某个章节。

#### Workspaces：工作区布局

> 不同任务需要不同的面板布局。

写作时你可能希望收起所有侧边栏只留编辑区，整理笔记时你需要文件列表和标签面板同时可见。

##### 保存工作区

调整好面板布局后，在左侧边栏的「工作区」面板中点击「管理工作区」，输入名称保存当前布局。

##### 切换工作区

在工作区面板中点击已保存的布局，一键切换。

##### 推荐的工作区布局

| 工作区  | 布局                                   |
| ---- | ------------------------------------ |
| 写作模式 | 关闭所有侧边栏，只留编辑区，专注内容输出                 |
| 整理模式 | 左侧：文件列表 + 标签面板，右侧：大纲 + 反向链接          |
| 研究模式 | 左侧：搜索结果，中间：主笔记 + Canvas，右侧：反向链接 + 大纲 |
| 回顾模式 | 左侧：书签，中间：日记 + 全局图谱，右侧：反向链接           |

### 第三方插件

- **定义：** 这些是由全球 Obsidian 用户（开发者）创建、维护和分享的第三方功能扩展。
- **特点：** 数量庞大，功能五花八门，极大地丰富了 Obsidian 的生态系统。
- **安全性：** 在安装第三方插件之前，Obsidian 默认开启**安全模式**。安装插件需要手动关闭安全模式，Obsidian 会提醒用户注意安全风险（建议只安装下载量大、评分高且功能明确的插件）。

##### 推荐的工作区布局

| 工作区  | 布局                                   |
| ---- | ------------------------------------ |
| 写作模式 | 关闭所有侧边栏，只留编辑区，专注内容输出                 |
| 整理模式 | 左侧：文件列表 + 标签面板，右侧：大纲 + 反向链接          |
| 研究模式 | 左侧：搜索结果，中间：主笔记 + Canvas，右侧：反向链接 + 大纲 |
| 回顾模式 | 左侧：书签，中间：日记 + 全局图谱，右侧：反向链接           |

#### 受欢迎的第三方插件

| 插件名称                 | 主要功能                                   | 典型应用场景                       |
| -------------------- | -------------------------------------- | ---------------------------- |
| **Dataview**         | 将你的笔记库视为一个数据库，用代码查询并展示数据。              | 自动生成任务列表、汇总所有带有特定标签的项目或书籍清单。 |
| **Excalidraw**       | 在 Obsidian 中创建手绘风格的图表和思维导图。            | 制作流程图、概念草图或进行手写注释。           |
| ==**Calendar**==     | 在右侧边栏显示一个日历视图。                         | 快速查看和跳转到过去的每日笔记，形成日程回顾。      |
| **Advanced Tables**  | 简化 Markdown 表格的创建和格式化。                 | 轻松对齐和编辑复杂的表格，无需手动调整空格。       |
| **Kanban**           | 在 Obsidian 中创建类 Trello 或 Notion 的看板视图。 | 任务管理、项目进度追踪或将想法从"待办"拖动到"完成"。 |
| ==**Obsidian Git**== | 自动将你的库备份到 Git 仓库（如 GitHub）。            | 实现版本控制和多设备同步，提供额外的安全保障。      |
