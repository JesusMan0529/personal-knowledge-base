## 1.1 数据、数据元素、数据项：三级层次关系

这一节建立了最基础的概念层级：**数据 > 数据元素 > 数据项**。

- **数据**：描述客观事物的符号集合，是信息的载体。它是最宏观的概念，比如班级里所有学生的信息加在一起就是"数据"。
- **数据元素**：组成数据的**基本单位**，计算机处理数据时把它当作一个整体。比如花名册中的"一行记录"（一个学生）。
- **数据项**：构成数据元素、具有独立含义的**不可分割最小单位**。比如一个学生记录中的"学号""姓名""成绩"。

简单记忆：**数据是全集，数据元素是其中的一个个体，数据项是个体的组成部分**。类比：学校（数据）→ 班级（数据元素）→ 学生个人（数据项）这样的层级。

## 1.2 数据结构的定义

> 数据结构是相互之间存在一种或多种特定关系的数据元素的集合。

关键在"**特定关系**"四个字——单独堆一堆数据不算数据结构，必须元素之间有某种关系才算。形式化表示为：

$$Data\_Structure = (D, R)$$

- $D$：数据元素的集合（有哪些元素）
- $R$：$D$ 中元素之间关系的集合（元素怎么关联）

也就是说，一个数据结构 = "有哪些数据" + "这些数据怎么组织"。

## 1.3 数据结构的三要素

一个完整的数据结构由三部分组成：**逻辑结构、存储结构、运算**。这是全章最重要的框架，后面所有章节（线性表、栈、队列、树、图）都是围绕这三要素展开的。

### ① 逻辑结构（抽象层面）

从逻辑上描述元素之间的关系，**与存储无关**，相当于"数据应该怎么组织"的设计蓝图。分类：

- **线性结构**："一对一"关系，元素排成一串。例：线性表、栈、队列。
- **非线性结构**：
  - **树形结构**："一对多"（一个节点可以有多个孩子）。例：树、二叉树。
  - **图结构**："多对多"（任意节点之间都可能相连）。例：图。

### ② 存储结构（物理层面）

数据在计算机里**实际怎么存放**，即逻辑结构的具体实现方式。四种：

| 存储方式 | 核心思想 | 优点 | 缺点 |
| --- | --- | --- | --- |
| 顺序存储 | 逻辑相邻的元素在物理位置上也相邻（如数组） | **随机存取**，访问快 | 可能产生碎片，插入/删除需移动元素 |
| 链式存储 | 用**指针**表示逻辑关系，物理位置不要求相邻（如链表） | 充分利用碎片空间，插入/删除方便 | 不能随机存取，需从头遍历 |
| 索引存储 | 额外建立索引表，通过索引定位元素 | 查找快 | 索引表占用额外空间 |
| 散列存储 | 根据关键字通过哈希函数直接计算存储地址 | 查找效率极高 | 存在哈希冲突问题 |

> 笔记里的提示：**随机存取** = 可以直接访问任意指定位置的元素，不用从头找。比如数组 `a[5]` 直接就能取到，而链表要找到第 5 个节点必须从第一个节点开始走。

### ③ 运算（操作层面）

定义在这组数据上允许执行的操作，如插入、删除、查找、修改等。

**三要素的关系**（重点）：一种**逻辑结构**可以用多种**存储结构**实现（比如线性表既可用数组实现，也可用链表实现）；而选择不同的存储结构，会让**运算**的效率产生差异——例如顺序存储删除元素要搬移数据、链式存储就不用。

## 1.4 数据类型、抽象数据类型（ADT）与数据结构

这一节解决三个概念"是什么、有什么区别、怎么串起来"的问题。

### 数据类型

- 定义：**一组性质相同的值的集合** + **定义在这组值上的一组操作**。比如 C 语言的 `int`：值集是某个整数范围，操作集是加减乘除取模等。
- 本质：是编程语言为了实现"**信息隐藏**"和"**数据封装**"引入的机制。

### 抽象数据类型 ADT（Abstract Data Type）

- 定义：基于一个逻辑类型的数据类型及其上的操作，包含**数据对象、数据关系、基本操作**三部分，常写作三元组 $(D, S, P)$。
- 核心思想：**封装与分离关注点**——把"**使用**"和"**实现**"分开。
  - 使用者只关心"它能做什么"（操作接口），比如 `push`/`pop`；
  - 实现者才关心"它怎么做"（内部细节）。
- 例子：线性表是个 ADT，定义了 `InitList`、`Insert`、`Delete`、`GetElem` 等操作，但**不关心**底层是数组还是链表。

### 三者关系

笔记给了一条清晰的链条：

$$数据类型 \rightarrow 抽象数据类型(ADT) \rightarrow 数据结构$$

- **数据类型是 ADT 的物理基础**：ADT 借鉴并扩展了数据类型的思想，从内置类型（`int`、`float`）提升到用户自定义的复杂逻辑结构（`List`、`Stack`）。
- **ADT 是数据结构的抽象描述**：ADT 定义了逻辑结构和运算，但不涉及存储结构。比如"栈"这个 ADT 定义了 LIFO（后进先出）特性和 `push`/`pop` 操作。
- **数据结构是 ADT 的物理实现**：当你用某门语言选一种存储结构，把 ADT 里定义的操作全部实现出来，就得到了一个具体的数据结构。
